This module extends Odoo's Email Marketing functionality to facilitate
the integration of partners (``res.partner``) with mailing contacts and
mailing lists.

It is based on the OCA modules ``mass_mailing_partner`` and
``mass_mailing_list_dynamic``, adapting and combining their
functionality to support partner imports, mailing list management, and
partner merging.

Usage
=====

Add partners to mailing lists
-----------------------------

1. Go to **Contacts**.
2. Select one or more partners from the list view.
3. Use the **Action** menu to open the wizard for adding partners to
   mailing lists.
4. Select one or more mailing lists.
5. Confirm the operation.

Mailing contacts are created automatically if they do not already exist.
Existing mailing contacts are reused, and only missing mailing list
subscriptions are added.

Partners must have an email address to be added to mailing lists.

Import partners using a domain
------------------------------

1. Go to **Email Marketing > Mailing Lists**.
2. Open a mailing list and access the contact import wizard.
3. Select **Partners** as the import type.
4. Configure the domain to filter the partners to import.
5. Confirm the import.

The module creates or reuses mailing contacts for the matching partners
and adds them to the selected mailing lists.

The standard email import functionality remains available by selecting
the email import type.

Merge partners
--------------

When merging partners that have linked mailing contacts, the module
automatically consolidates their mailing list subscriptions into a
single mailing contact associated with the destination partner.

Existing mailing list associations and opt-out preferences are
preserved.
